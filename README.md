# Sprint 7 - Dashboard de vehículos

## Descripción del proyecto

Esta aplicación web fue desarrollada utilizando Streamlit y permite analizar un conjunto de datos de vehículos usados en Estados Unidos.

La aplicación carga el archivo vehicles_us.csv y permite visualizar información a través de gráficos interactivos.

## Funcionalidades

- Visualización de un histograma de precios.
- Visualización de un gráfico de dispersión entre año del modelo y precio.
- Interfaz interactiva mediante botones.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

## Cómo ejecutar la aplicación

1. Clonar el repositorio:
   git clone https://github.com/Nanarobayo18/Sprint-7-dashboard.git

2. Entrar al directorio del proyecto:
   cd Sprint-7-dashboard

3. Crear y activar el entorno virtual (opcional pero recomendado):
   python -m venv venv
   venv\Scripts\activate   # En Windows

4. Instalar dependencias:
   pip install -r requirements.txt

5. Ejecutar la aplicación:
   streamlit run app.py
